# Lab 6 - Linear Regression on E-Commerce Customers

In this lab, we worked with an e-commerce customers dataset containing 500 records to predict how much a customer spends yearly. We started by exploring the data using visualizations like pair plots, histograms, and a correlation heatmap to understand relationships between features such as time spent on the app, time on the website, average session length, and length of membership. After confirming there were no missing values, we split the data into training and test sets, then trained a Linear Regression model. The model revealed that "Length of Membership" and "Time on App" are the strongest predictors of yearly spending. Finally, we evaluated the model's performance using MAE, MSE, and RMSE metrics, achieving an RMSE of ~9.69, which indicates the model predicts yearly spending within about $9.69 on average.
